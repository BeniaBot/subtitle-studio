# הלוגו

כל הקבצים כאן נוצרים מקוד, לא מתמונה — `build\make-logo.ps1` מצייר אותם
וקטורית ומרנדר ישירות בגודל המבוקש. אין כאן הגדלה של קובץ קטן.

```
powershell -ExecutionPolicy Bypass -File build\make-logo.ps1
```

| קובץ | מה זה | לאן |
|---|---|---|
| `logo-1024.png` · `512` · `256` · `128` · `64` | הסמל בלבד, רקע שקוף | אייקון אתר, אווטאר, חנות אפליקציות |
| `logo-name.png` | סמל + השם, לרוחב, רקע שקוף | כותרת אתר, מסמכים, מצגות |
| `logo-name-light.png` | אותו דבר בלבן | רקע כהה |
| `logo-wordmark.png` / `-light` | סמל + שם + שורת תיאור | באנר, פוסט |
| `logo-square.png` | ריבוע 1200 עם רקע בהיר | תמונת שיתוף ברשתות |

הצבעים: `#4C8DFF` → `#A97BFF` במעבר של 45°, על טקסט `#141822`.
הגופן הוא **Assistant** (‏OFL) מתוך `assets\fonts`.
